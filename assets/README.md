# LoopSteward brand assets

- `logo-mark.svg` — Möbius ribbon mark with an emerald twist, usable at 16 px and above.
- `logo.svg` — horizontal lockup for README and docs.
- `social-preview.svg` — 1280 x 640 GitHub social preview.
- `logo-mark.png` — 128 px raster mark.
- `logo.png` — 560 x 150 raster lockup.
- `social-preview.png` — 1280 x 640 raster social preview.

## Colors

| Token | Hex |
|---|---|
| Ink | `#0F172A` |
| Emerald | `#10B981` |
| Slate | `#475569` |
| Paper | `#F8FAFC` |
| Night | `#0B1220` |

## Rules

- Keep clear space around the mark of at least half the mark width.
- The emerald ribbon is the only accent; do not recolor it.
- Do not stretch, rotate, or add effects to the mark.
- Use `logo.svg` when the name is not already visible nearby.
